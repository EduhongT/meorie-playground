머리에 그리는® 놀이터: 카톡 미리보기·홈 화면 설치 파일

1. GitHub 저장소 meorie-playground 첫 화면에서 Add file → Upload files 를 누릅니다.
2. 이 묶음의 파일(주제가 theme-song.mp3, 노래 영상 song-video.mp4, song-poster.jpg 포함)과 icons 폴더를 모두 끌어다 놓습니다. (index.html 은 기존 파일을 덮어씁니다)
3. 아래 Commit changes 를 누르고 1~2분 기다립니다.
4. 카톡에서 미리보기가 예전 그대로면, 카카오 공유 디버거(https://developers.kakao.com/tool/debugger/sharing)에 앱 주소를 넣고 「캐시 초기화」를 누릅니다.
5. 나중에 앱을 고쳐 올릴 때는 sw.js 맨 위 playground-v6 을 playground-v7 처럼 올려 주세요. 그래야 홈 화면에 설치한 휴대폰에도 새 내용이 갑니다.
